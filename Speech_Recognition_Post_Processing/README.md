# Whisper -> NER를 통한 토큰의 언어 탐지 -> 토큰에 대한 텍스트 후처리 진행

---
## 위스퍼를 통한 음성 인식
일단 Speech to Text 는 whisper의 자동 언어 탐지 모드로 진행합니다. 이 때 한글같지 않은 단어도 일단은 영어와 비슷한 발음으로 번역하게 하기 위해 매개변수를 조정합니다.

--- 
## NER을 통한 토큰의 언어 탐지
AI Hub 데이터셋에 토큰별 <u>언어 및 품사 정보</u>를 태깅하는 전처리 과정을 진행합니다. 이를 통해 텍스트의 언어 및 품사를 탐지하는 NER 모델을 만듭니다.

---
## 토큰에 대한 텍스트 후처리 진
앞서 NER 과정을 통해서 탐지된 토큰을 영어로 바꾸는 과정입니다. 이 때 AI Hub 데이터셋의 form : originalForm 을 따로 모아주어서 발음을 기반으로 한글을 영어로 매핑해주는 모델을 만듭니다.
